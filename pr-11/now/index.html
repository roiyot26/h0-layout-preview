Coding agents in the team

I brought AI coding agents, and custom tooling around them, into the team's workflow to raise output without lowering quality. The team's setup is simpler than Kage. Every project carries its own rules file for the agent. Machine checks run first on every change, and a developer reads what's left: whether it does what was asked, anything touching data or accounts, and any decisions made mid-build.
