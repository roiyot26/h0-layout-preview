The same flow, step by step

  1. I give the orchestrator agent a one-line task.
  2. The orchestrator sends a query to the hybrid search, and ranked notes come back.
  3. The hybrid search runs over my notes vault, which is re-indexed on every commit.
  4. The orchestrator hands the worker agents a self-contained spec.
  5. The workers’ diff goes into a review gate run by a second model.
  6. Line-cited failures go back to the workers until none are left.
  7. Then comes my approval, then a pull request.
  8. The orchestrator writes decisions and what's still pending back to the vault.
